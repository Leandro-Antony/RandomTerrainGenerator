# RandomTerrainGenerator

## Descrição
Esse projeto consiste em um gerador de terreno aleatório que utiliza uma paleta de cores para identificar diferentes alturas e relevos.

As cores permitem a vizualização intuitiva do terreno, destacando áreas como água, planícies, montanhas e áreas elevadas.

## Funcionalidades
- Geração de mapa de relevo
- Possibilidade de gerar diferentes terrenos a cada execução
- Paleta de cores para identificar diferentes altitudes
- Geração e leitura de arquivos PPM
- Geração e salvamento de matriz de altitudes

# Tecnologias Utilizadas
- C++

## Como Executar

### Linux 
- Clone o repositório para um diretório da sua máquina
- Estando na pasta raiz do projeto, execute o comando `./mainLinux.out`

### Windows
- Clone o repositório para um diretório da sua máquina
- Estando na pasta raiz do projeto, execute o comando `./mainWindows.exe`
